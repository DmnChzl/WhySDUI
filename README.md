# Why SDUI

**Why SDUI** is a companion repository for the post "How to Server Driven UI? (And Why?)".

It contains a [Hono](https://hono.dev) server 🔥 that describes a preferences screen as a JSON schema, and a [Preact](https://preactjs.com) client ⚛️ that reads it, renders it, and sends changes back to the server.

The project is intentionally minimal: a single user, an in-memory store, and no authentication. It serves as the reference for the post's code, not as a production template.
